# Частотний словник частин мови (художній і науковий стилі)

Програма на Python автоматично укладає частотні словники словоформ, лем
і частин мови для двох українських текстів і зберігає результат у базу даних SQLite.
Дослідження проводилось на двох текстах різних функціональних стилів
(художній і науковий), по 20 000 слововживань.

## Що робить програма
- Очищує текст регулярними виразами (`re`).
- Обмежує вибірку до 20 000 слововживань і ділить на 20 підвибірок по 1000.
- Рахує частоти словоформ і лем (`Counter`, `defaultdict`).
- Визначає лему й частину мови через `pymorphy3` (українська мова),
  а для слів, які аналізатор визначає неправильно, використовує словники винятків.
- Записує результат у базу `frequency_dict.db`.

## Структура репозиторію
```
pos-frequency-dictionary/
├── frequency_dict.py     # програма
├── requirements.txt
└── results/              # графік і база даних
```

## Структура бази даних
Для кожного тексту створюються чотири таблиці (разом 8 для двох текстів):
- `ЧС_словоформ_*`: словоформа, загальна частота, частоти по підвибірках;
- `ЧС_лем_*`: лема, загальна частота, частина мови, частоти по підвибірках;
- `ЧС_частин_мови_*`: частина мови, загальна частота, частоти по підвибірках;
- `Проміжна_*`: словоформа, лема, частина мови, частоти.

Враховано 6 основних і 3 службові частини мови; дієприслівник записано як прислівник, дієприкметник як прикметник.


## Результат
На вибірках по 20 000 слововживань стилі помітно різняться. У науковому тексті іменники становлять 42,9% проти 30,9% у художньому, прикметники 19,4% проти 7,5%. У художньому більше дієслів (17,0% проти 9,9%) і займенників (11,9% проти 5,9%).

## Приклад запиту
```sql
SELECT лема, загальна_частота FROM ЧС_лем_vybirka2
ORDER BY загальна_частота DESC LIMIT 10;
```

## Як запустити
1. Підготуйте два текстові файли українською мовою (кодування UTF-8,  не менше 20 000 слів кожен) і покладіть їх у папку `data/sample/` під назвами:
   - `text1.txt` — перший текст
   - `text2.txt` — другий текст
2. Встановіть бібліотеки і запустіть:
```
pip install -r requirements.txt
python frequency_dict.py
```
Результат з'явиться у файлі `frequency_dict.db`.

## Дані
У репозиторії немає текстів для аналізу: користувач додає власні. Оригінальні тексти дослідження (роман і навчальний посібник) захищені авторським правом і не публікуються. Для запуску використовуйте тексти з публічного надбання, наприклад з [Вікіджерел](https://uk.wikisource.org).
Графік і скріншоти в `results/` отримані на оригінальних текстах.
